§ 7

princípios · quando você tem dúvida

01

colo, não dashboard

Se a tela parece uma cabine de avião, voltou pra prancheta. Médica abre o app cansada. Cada elemento que ela vê precisa ter motivo de existir.

02

uma decisão por tela

Cada tela tem 1 ação principal. As outras são suporte ou contexto. Se aparecer "qual eu clico primeiro?" é porque tem 2 primárias.

03

respiração antes de densidade

Whitespace é conteúdo. Antes de adicionar algo, perguntar se vale o ruído. Cada coluna nova é um ataque ao espaço.

04

cor diz o que importa

Cinza = neutro. Coral = atenção. Sage = ok. Lavender = brand/destaque. Se tudo é colorido, nada é. Cor é grifa, não decoração.

05

tempo é o eixo, não a navegação

Ela quer saber "quando?". Não "onde?". A hierarquia visual prioriza tempo (próximo plantão, dias até sexta) sobre estrutura (categorias, abas).

06

números são pessoas

"48h" é uma médica cansada. "R$ 2.200" é o aluguel. Nunca exibir métrica fria sem contexto humano · ao menos uma label que lembra do que é.

§ 8

anti-padrões · não faça

gradiente roxo-rosaAplicação não é app de meditação genérico. Use só washes lisos das famílias.
emoji em UINão temos vocabulário de emoji. Em comunicados editoriais é ok, na UI nunca.
card com left-border colorido + icone redondo + título grande + barra de progresso + 4 pillsSlop. Decida o que é importante e mostre só isso.
"Erro 500: ocorreu um problema"Se você não pode explicar o que aconteceu em humanês, pergunte ao designer/PM.
alertas vermelhos pra coisa não destrutivaCoral é conflito real. Atrasou 5min num plantão é sand, no máximo.
animação de mais de 280msApps lentos cansam. Tudo abre/fecha em 180–240ms · sem bounce, sem spring agressivo.
botão "OK" / "Cancelar"Sempre o verbo da ação · "aprovar troca" / "voltar pra agenda" · nunca confirma genérica.
Inter / Roboto / HelveticaFraunces + Nunito + Caveat. Fim. Mudar tipografia é mudar o produto.
